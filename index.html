🧠 1. CONCEPTOS FUNDAMENTALES Y ARQUITECTURA

QUÉ ES · PARA QUÉ SIRVE · POR QUÉ IMPORTA

0.1. ¿Qué es DeepSeek Harness y qué es el Modo CREADOR?

¿Qué es? DeepSeek Harness es la aplicación de escritorio nativa desarrollada para ejecutar modelos de inteligencia artificial de manera local e interactiva en tu ordenador (macOS o Windows). A diferencia de una página web de chat convencional, un "harness" (arnés o contenedor de ejecución) es un entorno de software capaz de alojar herramientas, scripts, motores gráficos en 3D y módulos de programa integrados.

¿Para qué sirve el Modo CREADOR (Creator Mode)? Es una función dentro de la aplicación de escritorio que desbloquea la capacidad de modificar la propia arquitectura de la interfaz. En lugar de limitarte a conversar con un modelo de texto, el Modo CREADOR te permite pedirle a la IA en lenguaje natural que programe, compile, instale y configure nuevos paneles laterales, editores de vídeo, monitores de gasto en dólares, videojuegos 3D y conectores de datos en tiempo real.

¿Por qué importa? Porque elimina la barrera de saber programar: cualquier usuario puede crear software a medida que queda guardado de forma permanente (persistente) en la barra lateral de su ordenador.

0.2. Arquitectura Desbloqueada frente a Plataformas Cerradas

Las plataformas comerciales cerradas (como las versiones web tradicionales de suscripción) imponen límites estrictos de mensajes, cuotas mensuales fijas y una interfaz rígida que el usuario no puede alterar. DeepSeek Harness opera bajo una arquitectura desbloqueada:

Característica Plataformas Web Cerradas DeepSeek Harness (Modo Creador)
Peajes y Suscripciones Cuota mensual obligatoria para funciones avanzadas. Descarga gratuita y código abierto. Permite omitir recargas de saldo usando proveedores gratuitos.
Elección de Modelos Restringido al proveedor propietario de la web. Libertad total: API oficial de DeepSeek, cuentas de ChatGPT, modelos locales (Ollama) u OpenRouter con modelos 100% gratuitos (free).
Interfaz de Usuario Estática e inmodificable por el usuario. Extensible mediante el framework interno Cordis y el Plugin Manager.
Persistencia Conversaciones aisladas en la nube. Cada plugin generado se instala en el sistema operativo local y permanece activo al reiniciar.

1.4. El Prefijo Universal en Inglés: Regla de Oro

Para que cualquier plugin que solicites genere un acceso directo permanente en la barra lateral izquierda de la aplicación, debes anteponer siempre esta frase exacta en inglés al comienzo de tu prompt:

Prefijo Universal Obligatorio (Prompts 01 al 07 y 09 al 12) 
Create a DSH plugin with a left sidebar entry.

¿Existe alguna excepción? Sí: únicamente el Prompt 08 (Investigar con DeepWiki) no lleva este prefijo, porque no construye un nuevo panel visual en la barra lateral, sino que realiza una consulta directa de investigación al conector MCP previamente instalado con el Prompt 11.

Procedimiento 01 · Instalación del Entorno

Descarga e Instalación de DeepSeek Harness en macOS y Windows

Objetivo: Instalar la aplicación de escritorio nativa de DeepSeek Harness en tu ordenador superando los avisos preventivos del sistema operativo.

Opción A: Instalación paso a paso en macOS

  1. Accede a la web oficial de descarga de DeepSeek Harness: Esto garantiza obtener el instalador legítimo sin modificaciones de terceros.
  2. Descarga el archivo .dmg correspondiente a tu procesador (Apple Silicon M1-M4 o Intel): Elegir la arquitectura correcta evita errores de emulación y maximiza el rendimiento gráfico.
  3. Haz doble clic sobre el archivo .dmg descargado: Se montará la ventana virtual de instalación en el escritorio de macOS.
  4. Arrastra el icono de DeepSeek Harness hacia la carpeta Aplicaciones: Así el programa queda instalado de forma permanente en el disco local.
  5. Abre la aplicación desde Aplicaciones y autoriza su ejecución si aparece Apple Gatekeeper: Si macOS muestra un aviso de seguridad, entra en Ajustes del Sistema → Privacidad y Seguridad y pulsa en Abrir de todos modos.

Opción B: Instalación paso a paso en Windows (10 / 11 de 64 bits)

  1. Descarga el instalador ejecutable .exe oficial de DeepSeek Harness: Obtendrás el paquete autoinstalable para sistemas Windows de 64 bits.
  2. Haz doble clic sobre el archivo .exe descargado: Se iniciará el asistente de configuración del sistema.
  3. Si aparece Windows Defender SmartScreen, pulsa en Más información y luego en Ejecutar de todos modos: Esto autoriza la instalación de software de código abierto recién publicado.
  4. Marca la casilla "Crear acceso directo en el escritorio" y finaliza el asistente: Tendrás acceso inmediato al entorno de desarrollo.

✅ Resultado esperado: La ventana principal de DeepSeek Harness se abre limpia en tu pantalla mostrando la barra lateral izquierda y el cuadro central de conversación.

Procedimiento 02 · Modelos 100% Gratuitos

Conexión Paso a Paso con OpenRouter para Usar IA Gratis (Sin Pagar Créditos)

Objetivo: Configurar motores de inteligencia artificial gratuitos dentro de DeepSeek Harness para crear plugins sin gastar dinero en APIs de pago.

Explicación sencilla: Al abrir DeepSeek Harness por primera vez, puede aparecer un aviso invitándote a recargar saldo para la API oficial de DeepSeek. No es obligatorio pagar. Puedes conectar una clave gratuita de OpenRouter, conectarte con credenciales/tokens de tu cuenta de ChatGPT o usar la API oficial de DeepSeek si ya tenías saldo.

Fase 1: Obtener tu clave API gratuita en OpenRouter

  1. Abre tu navegador web y entra en la plataforma OpenRouter: Es el agregador oficial donde generaremos la llave de acceso sin coste.
  2. Crea una cuenta gratuita o inicia sesión con tu correo: Necesitas un perfil activo para administrar tus claves.
  3. Dirígete al menú Keys (Claves API) y pulsa el botón Create Key: Esto abrirá el formulario de creación de credenciales.
  4. Escribe un nombre identificativo (por ejemplo, Harness-Free) y fija el límite de gasto (Credit limit) en $0.00: Poner el límite en cero garantiza que jamás se te cobre nada por error.
  5. Haz clic en Create y copia la clave generada (comienza por sk-or-v1-...): Guárdala en el portapapeles porque solo se muestra completa una vez.

Fase 2: Vincular OpenRouter dentro de DeepSeek Harness

  1. Haz clic en el icono de rueda dentada de Ajustes (Settings) dentro de DeepSeek Harness: Se abrirá el panel de administración de la aplicación.
  2. Selecciona la pestaña Modelos (Models) o Proveedores (Providers) y pulsa Añadir Proveedor: Aquí se registran los motores de inteligencia artificial externos.
  3. Elige OpenRouter en la lista predefinida y pega tu clave sk-or-v1-... en el campo API Key: El arnés quedará autenticado contra el catálogo de modelos de OpenRouter.
  4. Pulsa en Guardar y abre el selector de modelos en la barra superior del chat: Verás la barra de búsqueda de modelos disponibles.
  5. Escribe la palabra free en el buscador de modelos: El sistema filtrará exclusivamente los modelos 100% gratuitos (como deepseek/deepseek-r1:free, meta-llama/llama-3.3-70b-instruct:free o google/gemini-2.0-flash-lite-free).
  6. Selecciona un modelo gratuito y ajusta el Nivel de Esfuerzo (Effort Level) en Medio o Alto: Para programar plugins complejos o entornos 3D, un esfuerzo Medio o Alto permite que la IA razone entre 5 y 15 minutos generando código robusto sin errores de sintaxis.

Procedimiento 03 · El Flujo Maestro de Compilación

Cómo Activar el Modo Creador y Compilar Cualquier Plugin

  1. Ubica el selector de modo en la barra superior de DeepSeek Harness (junto al nombre del modelo): Por defecto la aplicación arranca en Standard Mode.
  2. Cambia el selector de Standard Mode a Creator Mode: Esto habilita los permisos internos de escritura de código, acceso a Cordis y gestión del Plugin Manager.
  3. En la caja inferior donde escribes tus mensajes, haz clic en el botón + o More: Se desplegará el menú de acciones especiales del entorno.
  4. Haz clic en la opción Crear un plugin (Create Plugin): El sistema insertará una etiqueta de contexto indicando al agente que la próxima orden debe empaquetarse como un módulo instalable.
  5. Pega el prompt completo comenzando siempre por Create a DSH plugin with a left sidebar entry. y pulsa Enviar: El agente diseñará la arquitectura, escribirá el código, lo instalará y lo verificará automáticamente.
  6. Itera desde el chat si deseas cambios adicionales: Una vez que el plugin aparezca en la barra lateral izquierda, puedes escribir en el mismo chat órdenes como "Cambia el fondo a violeta" o "Añade un filtro por fecha" para que el agente recompile la mejora al instante.
Procedimiento 04 · Guía Técnica de los 12 Desarrollos

Especificaciones Paso a Paso de Todas las Herramientas del Tutorial

Despliega o revisa cada uno de los bloques siguientes para comprender cómo funciona cada plugin por dentro, qué exige su arquitectura y cómo validar que se ha construido sin simulaciones falsas:

1. Task Celebration HUD (Cronómetro Gigante + Confeti Real)

Qué es y para qué sirve: Un widget flotante siempre visible construido sobre la superficie oficial shell.overlay de Cordis. Muestra un cronómetro gigante en formato MM:SS mientras la IA trabaja y lanza confeti durante 3 segundos junto a un check verde y sonido opcional cuando la tarea concluye con éxito.

Requisitos técnicos críticos:

  • Escucha los eventos reales de sesión: session/event, turn/start y turn/end.
  • Regla de integridad: Solo lanza confeti cuando se cumple estrictamente reason.kind === "completed". No celebra si la tarea se cancela, falla, queda bloqueada o se corta por límite de tokens.
  • Muestra 6 estados claros: Trabajando, Usando herramientas, Esperando permiso, Completado, Cancelado y Error, además del historial de duración de las últimas 5 tareas.
2. AI Usage Monitor (Auditoría Financiera de Tokens y Contexto)

Qué es y para qué sirve: Panel flotante minimizable que monitoriza en tiempo real el consumo de tokens (entrada, salida, caché y razonamiento), la presión sobre la ventana de contexto y el coste estimado en dólares (USD) por tarea, sesión e histórico.

Reglas de Oro de Datos Reales:

  • Consulta las proyecciones nativas tokenUsage, contextPressure, contextWindow y projectedTokens.
  • No duplicar tokens de razonamiento: Verifica que no se sumen dos veces si el proveedor ya los incluye dentro de los tokens de salida.
  • Honestidad de datos: Nunca confunde cuota de cuenta con contexto restante. Si un proveedor no ofrece API de saldo o tarifas verificables, muestra "Cuota de cuenta: no disponible" o "Estimación incompleta" en lugar de inventar números.
3. Mi Espacio (Tablero Kanban con Control Bidireccional por Chat)

Qué es y para qué sirve: Aplicación persistente de productividad con tres columnas (Ideas, En proceso y Completado). Permite crear tarjetas con título, descripción, etiquetas de colores, fecha límite y listas de verificación (checklists), además de moverlas arrastrando y soltando (Drag & Drop).

Conexión real con el agente: El tablero expone herramientas internas para que puedas escribir en el chat "Organiza mis ideas para el próximo vídeo" o "Marca como completada la investigación" y el agente cree o mueva las tarjetas automáticamente en tiempo real.

4. Mission Control (Centro de Mando Global Multisesión)

Qué es y para qué sirve: Dashboard ejecutivo para supervisar todas tus sesiones abiertas e inactivas de DeepSeek Harness al mismo tiempo. Cada sesión muestra su tarjeta con el modelo activo, cronómetro independiente, estado (trabajando, esperando, completado, error o inactivo), número de llamadas a herramientas y coste estimado. Al hacer clic en una tarjeta, navegas directamente a esa conversación.

5. Estudio Creativo (Taller de Miniaturas YouTube 16:9 en PNG 1280×720)

Qué es y para qué sirve: Estudio de diseño gráfico en español para crear miniaturas de YouTube en formato 16:9. Arranca con una composición de impacto con el texto "LA IA LO CAMBIA TODO", fondos con shaders animados, degradados, paletas de un clic, subida de logos propios y edición desde el chat (ej. "Cambia el fondo a violeta").

Validación de exportación: Debe exportar un archivo PNG real de $1280 \times 720$ píxeles a tu disco duro.

6. MiniCut (Editor de Vídeo Funcional MP4 con FFmpeg)

Qué es y para qué sirve: Editor de vídeo no lineal simplificado dentro de Harness. Su primera versión obligatoria permite: 1) Importar dos archivos .mp4 locales, 2) Previsualizarlos, 3) Colocarlos en una línea de tiempo (timeline), 4) Recortar el principio (In) y final (Out) de cada clip, 5) Reordenarlos, y 6) Exportar un único archivo .mp4 real y reproducible fuera de DeepSeek Harness.

Gestión de FFmpeg: Si el entorno necesita la herramienta FFmpeg, el agente primero inspecciona el sistema y te pide autorización antes de instalarla. Una vez validado, permite ediciones por voz/texto en el chat como "recorta los primeros tres segundos del segundo vídeo".

7. IA Generativa en 3D (Laboratorio Didáctico Tridimensional)

Qué es y para qué sirve: Simulación interactiva en 3D que explica visualmente cómo procesa la información un modelo de lenguaje: desde la conversión del texto en tokens y vectores multidimensionales, pasando por las capas de mecanismos de atención, hasta el cálculo de probabilidades del siguiente token.

Cuidado de diseño en macOS: El prompt exige mantener el título del panel y la barra de herramientas libres de los botones nativos de ventana de macOS (Traffic Lights: cerrar, minimizar, maximizar) para evitar superposiciones.

8. Escape AI (Videojuego 3D Interactivo con Físicas y Colisiones)

Qué es y para qué sirve: Videojuego 3D en primera o tercera persona ambientado en un laboratorio futurista con estética low-poly. Incluye dos habitaciones conectadas, control con teclas WASD y ratón, obstáculos con colisiones reales, una llave recolectable (tecla de interacción), una puerta bloqueada que solo se abre con la llave, temporizador y pantalla de victoria.

9. Earth Live (Globo Terráqueo 3D con APIs Oficiales de USGS y NASA EONET)

Qué es y para qué sirve: Centro de control espacial en 3D en la barra lateral que dibuja en las coordenadas geográficas exactas del planeta Tierra los desastres y eventos naturales en tiempo real.

  • Terremotos (últimas 24h - USGS GeoJSON): https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson
  • Eventos Naturales Activos (NASA EONET): https://eonet.gsfc.nasa.gov/api/v3/events?status=open

Permite girar y hacer zoom sobre el globo, filtrar por magnitud/categoría/fecha y abrir fichas con enlaces a la fuente oficial. Si una API falla, informa del error sin inventar datos de demostración.

10 y 11. Conector DeepWiki MCP e Investigación del Repositorio Oficial

Paso 1 (Prompt 11 - Instalar DeepWiki MCP): Registra en el perfil actual un conector MCP real llamado deepwiki apuntando al endpoint https://mcp.deepwiki.com/mcp mediante transporte Streamable HTTP (sin autenticación para repositorios públicos).

Paso 2 (Prompt 08 - Investigar con DeepWiki): Una vez activo el servidor MCP, se envía este prompt directamente en el chat (sin el prefijo en inglés) para que el agente consulte exclusivamente con las herramientas de DeepWiki el repositorio oficial deepseek-ai/deepseek-harness y extraiga la documentación real sobre Cordis, shell.overlay, eventos de sesión y Plugin Manager.

12. Retro AI OS y Marca Blanca (Rebranding de Nombre, Logo y Fuentes)

Retro AI OS (Prompt 09): Transforma visualmente DeepSeek Harness en un sistema operativo pixel art de los años 90 con ventanas clásicas, interruptor de encendido/apagado persistente y una mascota pixel art original que reacciona en vivo cuando el agente está trabajando, esperando aprobación o ha terminado.

Rebranding / Marca Blanca (Nombre y Logotipo Propio):

❓ 5. 33 PREGUNTAS Y RESPUESTAS ORDENADAS POR NIVEL DE DIFICULTAD

Pon a prueba y consolida todo tu dominio de DeepSeek Harness Creator Mode con las 33 preguntas y respuestas oficiales estructuradas en tres niveles progresivos de dificultad: Nivel 1 (Básico: 1 a 11), Nivel 2 (Avanzado: 12 a 22) y Nivel 3 (PRO: 23 a 33).

🟢 Nivel 1 — Básico (Preguntas 1 a 11)

Nivel 1 1. ¿Es necesario saber programar para utilizar el Modo CREADOR de DeepSeek Harness?

No. El Modo CREADOR está diseñado para que cualquier persona pueda construir aplicaciones escribiendo instrucciones en español neutro. El agente de IA se encarga de redactar, estructurar e instalar el código técnico por ti.

Nivel 1 2. ¿Tengo que pagar obligatoriamente por una suscripción mensual para usar la aplicación?

No. La aplicación de escritorio DeepSeek Harness es de código abierto y descarga gratuita. Además, puedes conectar proveedores con modelos 100% gratuitos como OpenRouter sin gastar dinero.

Nivel 1 3. ¿En qué sistemas operativos puedo instalar DeepSeek Harness?

Está disponible formalmente con instaladores sencillos para macOS (tanto procesadores Apple Silicon M-Series como Intel) y Windows (10 y 11 de 64 bits).

Nivel 1 4. ¿Para qué sirve el prefijo Create a DSH plugin with a left sidebar entry.?

Es una instrucción técnica universal en inglés que le indica al motor del arnés que debe compilar el plugin de forma que cree una pestaña o acceso directo permanente en la barra lateral izquierda de la interfaz.

Nivel 1 5. ¿Dónde se encuentra el botón para activar el Modo CREADOR?

Se ubica en la barra superior de la aplicación, en el desplegable de modos junto a la selección del modelo de IA, cambiando la opción de Standard Mode a Creator Mode.

Nivel 1 6. ¿Qué ocurre si me aparece un aviso solicitando recargar créditos al iniciar la aplicación?

Puedes ignorar o cerrar la advertencia. No es obligatorio recargar saldo si decides conectar tu propia clave API de OpenRouter o vincular tu cuenta existente.

Nivel 1 7. ¿Qué es OpenRouter y por qué se recomienda en el tutorial?

OpenRouter es un servicio unificado que agrupa decenas de modelos de IA de distintos desarrolladores. Se recomienda porque ofrece multitud de modelos potentes de uso totalmente gratuito utilizando la etiqueta de búsqueda free.

Nivel 1 8. ¿Se borran mis plugins creados al cerrar la aplicación DeepSeek Harness?

No. Todos los plugins instalados en Modo CREADOR son persistentes y continúan disponibles en la barra lateral cada vez que vuelves a abrir la aplicación.

Nivel 1 9. ¿Qué es el widget Task Celebration HUD?

Es un plugin que muestra un cronómetro grande en pantalla mientras la IA procesa una tarea y lanza una animación festiva de confeti cuando el trabajo concluye con éxito.

Nivel 1 10. ¿Puedo cambiar el aspecto visual de la aplicación para que parezca un sistema operativo antiguo?

Sí. Utilizando el plugin Retro AI OS, la interfaz adopta una estética pixel art retro inspirada en los sistemas informáticos de los años 90.

Nivel 1 11. ¿Dónde se encuentra el menú para añadir nuevas claves API de modelos?

Se accede haciendo clic en el icono de rueda dentada de Ajustes (Settings) en la esquina superior de la ventana y seleccionando la sección de Modelos o Proveedores.

🟡 Nivel 2 — Avanzado (Preguntas 12 a 22)

Nivel 2 12. ¿Cómo funciona la interacción entre el chat de la conversación y un plugin como Mi Espacio?

El plugin conecta sus elementos visuales (como el tablero Kanban) con las herramientas internas del agente de IA, permitiendo que las órdenes escritas en el chat (como "añade una tarea") modifiquen directamente el estado de las tarjetas.

Nivel 2 13. ¿Qué resolución y formato exige el prompt del plugin Estudio Creativo para sus exportaciones?

Exige la generación e independización de archivos de imagen en formato PNG con una resolución exacta de $1280 \times 720$ píxeles en formato de aspecto $16:9$.

Nivel 2 14. ¿Qué sucede si mi sistema no tiene instalado FFmpeg al intentar exportar un vídeo con el plugin MiniCut?

El plugin detectará la ausencia de la dependencia en el entorno local y solicitará la autorización del usuario en la pantalla de chat antes de proceder a su descarga e instalación.

Nivel 2 15. ¿De dónde obtiene el plugin Earth Live la información sobre terremotos y desastres naturales?

Se conecta en tiempo real a las APIs abiertas oficiales del Servicio Geológico de EE. UU. (USGS GeoJSON) para datos sísmicos y de la NASA (EONET API) para incendios y tormentas.

Nivel 2 16. ¿Cuál es la diferencia entre el consumo de tokens y la ventana de contexto en AI Usage Monitor?

El consumo de tokens mide el volumen de datos procesados (entrada y salida), mientras que la ventana de contexto representa el porcentaje ocupado del espacio máximo de memoria disponible para esa sesión.

Nivel 2 17. ¿Por qué se recomienda ajustar el nivel de esfuerzo del modelo en "Medio" o "Alto" al crear plugins?

Porque compilar código ejecutable de alta calidad e interfaces 3D requiere que el modelo dedique mayor tiempo de procesamiento interno a resolver la arquitectura lógica sin cometer errores de sintaxis.

Nivel 2 18. ¿Cómo evita AI Usage Monitor contabilizar datos duplicados de tokens de razonamiento?

El código del plugin verifica la estructura de respuesta de la API y garantiza que los tokens de razonamiento (reasoning tokens) no se sumen a la cuenta total si el proveedor ya los incluye dentro de la cifra de tokens de salida.

Nivel 2 19. ¿Qué mecánicas de control requiere el videojuego 3D Escape AI para validar su funcionamiento?

Requiere desplazamiento con teclas WASD, control de cámara con el ratón, interacción de inventario con la tecla E para recoger una llave y desbloquear la puerta de salida, e incluye sistema de colisiones.

Nivel 2 20. ¿Qué se debe hacer si los controles de un plugin 3D tapan los botones nativos de cierre de ventana en Mac?

Se debe especificar en el prompt del plugin la restricción explícita de dejar libre la esquina superior de la interfaz para evitar superposiciones con los botones del sistema operativo (Traffic Lights).

Nivel 2 21. ¿Qué información muestra el panel Mission Control sobre las sesiones abiertas?

Muestra el modelo asignado, el estado de ejecución (Trabajando, Esperando, Completado, Error o Inactivo), el tiempo de procesamiento, el número de herramientas llamadas y accesos directos de navegación.

Nivel 2 22. ¿Se pueden subir imágenes y fondos propios dentro del plugin Estudio Creativo?

Sí. La especificación del plugin incluye controles para cargar archivos de imagen y logotipos locales desde el disco duro para integrarlos en la miniatura.

🟣 Nivel 3 — PRO (Preguntas 23 a 33)

Nivel 3 23. ¿Qué es el protocolo MCP (Model Context Protocol) y cuál es su función en Harness?

Es un estándar cliente-servidor que permite a la IA conectar de forma segura con servidores remotos de herramientas, extrayendo información estructurada o ejecutando comandos en plataformas externas.

Nivel 3 24. ¿Qué endpoint y protocolo de transporte utiliza el plugin de instalación de DeepWiki MCP?

Utiliza el endpoint https://mcp.deepwiki.com/mcp bajo el protocolo de transporte Streamable HTTP, el cual no requiere autenticación previa para repositorios de acceso público.

Nivel 3 25. ¿Cómo se ejecuta una búsqueda técnica en el repositorio de GitHub de DeepSeek mediante MCP?

Una vez conectado el servidor MCP deepwiki, se envía una consulta (como el Prompt 08) especificando el repositorio objetivo (deepseek-ai/deepseek-harness) para inspeccionar su código y manuales.

Nivel 3 26. ¿Qué es el sistema Cordis dentro de la arquitectura de DeepSeek Harness?

Es la infraestructura y framework interno sobre el cual se construyen, registran y gestionan las extensiones, eventos de sesión y superficies flotantes en el entorno de la aplicación.

Nivel 3 27. ¿Cómo se lleva a cabo el proceso de marca blanca o rebranding completo en DeepSeek Harness?

Se le solicita al agente en Modo CREADOR que modifique el título del arnés y el archivo de icono gráfico, seguido de un reinicio completo de la aplicación para que el sistema recargue la interfaz modificada.

Nivel 3 28. ¿Qué condición de evento específica evita que Task Celebration HUD lance confeti en tareas fallidas?

La comprobación de la propiedad reason.kind === "completed" en la carga útil del evento de sesión (turn/end), descartando eventos cancelados, bloqueados o interrumpidos por errores.

Nivel 3 29. ¿Cómo se gestionan las fuentes de datos en Earth Live cuando un servidor externo de la NASA o USGS no responde?

El plugin captura la excepción de red y despliega un aviso claro de error en la interfaz sin inventar eventos sísmicos ni rellenar la pantalla con datos falsos de simulación.

Nivel 3 30. ¿Qué diferencia existe entre las variables contextPressure y projectedTokens en la API de Harness?

contextPressure calcula la carga porcentual actual del búfer de memoria, mientras que projectedTokens realiza una estimación del espacio de contexto que ocupará la respuesta que se va a generar.

Nivel 3 31. ¿Es posible deshabilitar temporalmente un plugin sin desinstalarlo de la aplicación?

Sí. Accediendo al menú de Plugins en la aplicación, es posible cambiar el conmutador de activación (Habilitar / Deshabilitar) de cualquier complemento de forma individual.

Nivel 3 32. ¿Cómo se conecta una clave de API de OpenAI u otro proveedor externo usando OpenRouter?

OpenRouter actúa como intermediario: ingresas tu clave de OpenRouter en Harness y, desde el catálogo de OpenRouter, seleccionas la API del proveedor de destino manteniendo una única configuración.

Nivel 3 33. ¿Cuál es el procedimiento recomendado para depurar un plugin que presenta errores visuales en su código?

Se debe utilizar el chat de la sesión donde se creó el plugin para solicitar la corrección (ejemplo: "El botón de exportar no responde al hacer clic, revisa la función de disparo y actualiza el plugin"), permitiendo que el agente recompile el módulo.

9.4. Discrepancias en Contadores de Tokens o Cuotas No Disponibles

Síntoma: En el plugin AI Usage Monitor aparece el mensaje "Cuota de cuenta: no disponible" o la cifra de tokens parece el doble de la real en modelos razonadores (como DeepSeek R1).

Causa y Solución: Muchos proveedores gratuitos o locales no exponen un endpoint público de saldo monetario; en ese caso, mostrar "No disponible" es el comportamiento honesto esperado (nunca debe confundirse con la ventana de contexto restante). Si los tokens están inflados, pídele al agente en el chat: "Revisa el cálculo de AI Usage Monitor para no sumar dos veces los tokens de razonamiento cuando ya vienen incluidos dentro de los tokens de salida".

9.5. Fallo de Conexión o Tiempo de Espera Agotado en Servidores MCP

Síntoma: Al ejecutar el Prompt 08 de investigación con DeepWiki MCP, el agente indica que las herramientas no responden o hay error de red.

Causa y Solución:

  1. Verifica tu conexión a Internet.
  2. Comprueba que ejecutaste primero el Prompt 11 configurando exactamente el endpoint https://mcp.deepwiki.com/mcp con transporte Streamable HTTP.
  3. Reinicia DeepSeek Harness si el Plugin Manager solicitó recargar la sesión tras registrar el bundle MCP.
